# Tractform

Systems for life on the land.

Tractform is a modular planning tool that calculates space, livestock, buildings, and farming requirements so people can shape a practical, livable homestead.

## Live site

- GitHub: https://github.com/alexkikalo/tractform
- Vercel: https://tractform-alex-kikalos-projects.vercel.app

## Custom domain

Point `tractform.com` to the Vercel project:

1. In Vercel → Project Settings → Domains → Add `tractform.com`
2. Add the DNS records Vercel provides at your domain registrar

## Stack

Simple static landing page (HTML + Tailwind via CDN). Ready to expand into a full Next.js app when needed.
